# Telegram-бот для записи клиентов в бьюти-сфере

Бот для управления записями клиентов с гибкой системой кастомизации и автономным управлением услугами и расписанием.

## Технологии

- Python 3.8+
- aiogram 3.4.1
- PostgreSQL (asyncpg)
- Асинхронная архитектура

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Отредактируйте файл `.env` и заполните все необходимые настройки:
- `BOT_TOKEN` - токен бота от @BotFather (обязательно)
- `ADMIN_ID` - ваш Telegram ID, получить можно у @userinfobot (обязательно)
- `LOG_ADMIN_ID` - ID для системных логов (по умолчанию такой же как ADMIN_ID)
- `DB_HOST` - хост базы данных PostgreSQL (обязательно)
- `DB_PORT` - порт базы данных (обязательно)
- `DB_NAME` - имя базы данных (обязательно)
- `DB_USER` - пользователь базы данных (обязательно)
- `DB_PASSWORD` - пароль базы данных (обязательно)
- `MASTER_TIMEZONE` - часовой пояс мастера (например: Europe/Moscow)

4. Создайте базу данных PostgreSQL:
```bash
createdb beauty_bot
```

5. Запустите бота:
```bash
python main.py
```

## Основные функции

### Клиентская часть

- Приветственное сообщение
- Выбор услуги с просмотром цены и длительности
- Выбор даты и времени записи
- Просмотр текущих записей
- Редактирование записей (с уведомлением мастера)
- Связь с мастером
- Информационные разделы (адрес, контакты, соцсети и т.д.)
- FAQ
- Напоминания о записях

### Админ-панель

Команда `/admin` открывает админ-панель (доступ только для администраторов).

- **Управление услугами**: CRUD операции
- **Управление расписанием**: настройка рабочего времени по дням
- **Управление клиентами**: просмотр, заметки, теги, черный список
- **История записей**: просмотр всех записей
- **Настройки бота**: подтверждение записей, настройки напоминаний
- **Управление информацией**: редактирование адреса, контактов, FAQ

## Особенности

### Часовые пояса

Бот автоматически определяет часовой пояс клиента (планируется) и показывает все время в часовом поясе мастера, указанном в конфигурации.

### Расписание

Мастер может:
- Выбрать дату из календаря
- Установить рабочие часы в формате ЧЧ:ММ-ЧЧ:ММ
- Пометить день как выходной
- Листать календарь на год вперед

### Напоминания

Система автоматических напоминаний:
- За 24 часа до записи
- За 1-2 часа до записи
- Повторные напоминания через заданный интервал (если клиент не подтвердил)
- Кнопка "Подтвердить, что приду" с уведомлением мастера

### Уведомления мастеру

Мастер получает уведомления о:
- Новой записи (с возможностью подтверждения)
- Отмене записи
- Переносе записи
- Неподтвержденных записях

### Обработка ошибок

Все ошибки автоматически отправляются администратору (ID из конфигурации) с полной трассировкой стека.

## Расширение функционала
